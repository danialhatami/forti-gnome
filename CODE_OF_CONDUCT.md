# Code of Conduct

Be kind and respectful. Disagree with ideas, not with people.
No harassment, insults or discrimination. Do not share other people's private information.
English is not the first language of many of us, so please be patient.

Maintainers can edit or remove comments, issues and pull requests that break these rules, and can block people who keep breaking them.
To report a problem, contact the maintainer privately on GitHub.
